# Registro del frontend del TP

Esta carpeta resume el trabajo realizado en el frontend de Tecnologías Web (Angular).
Cada archivo cubre una etapa y usa el mismo formato que el registro del backend:
**Usuario** (qué se pidió) y **Asistente** (qué se hizo y por qué).

No contiene credenciales: las contraseñas de la base quedaron solo en Render.

- `2026-11-25_21-14_zoneless-y-cargando.md` — bug de “Cargando...” y solución con `markForCheck()`.
