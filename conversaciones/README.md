# Registro del frontend del TP

Esta carpeta resume el trabajo realizado en el frontend de Tecnologías Web (Angular).
Cada archivo cubre una etapa y usa el mismo formato que el registro del backend:
**Usuario** (qué se pidió) y **Asistente** (qué se hizo y por qué).

No contiene credenciales: las contraseñas de la base quedaron solo en Render.

## Archivos

- `2026-11-25_20-40_inicio-frontend.md` — generación del proyecto, servicio y CRUD de competiciones.
- `2026-11-25_21-10_deploy-y-postman.md` — Render, Netlify, `_redirects` y carga de datos.
- `2026-11-25_21-14_zoneless-y-cargando.md` — bug de “Cargando...” y solución con `markForCheck()`.
- `2026-11-25_21-32_entrega2-crud-autos.md` — errores en UI, edición, módulo de autos y responsive.
- `2026-11-25_resumen-final.md` — estado final, URLs, commits y verificación.
- `2026-11-26_estetica.md` — fondo, botones y menú lateral izquierdo.
- `2026-11-26_menu-inicial.md` — pantalla de inicio con título y dos botones, imagen de fondo.
- `2026-11-26_buscar-y-filtrar.md` — buscadores y autos por competición.
- `2026-11-26_detalle-y-extras.md` — orden, recarga, confirmación de borrado y vista de detalle.
- `2026-11-26_render-static-site.md` — Netlify pausado por créditos y deploy alternativo en Render.
- `resumen-frontend.md` — resumen técnico completo: rutas, servicios y checklist.
- `RESUMEN-PARA-ENTREGA.md` — resumen de las conversaciones del frontend para entregar.
